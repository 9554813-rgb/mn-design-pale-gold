# MN DESIGN — Pale Gold

Статический сайт студии интерьеров. Откройте index.html или разместите файлы на статическом хостинге.

## GitHub Pages

Загрузите содержимое этой папки в корень публичного репозитория. В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root).

## Изображения

Файлы изображений находятся в корне репозитория. Для замены можно сохранить прежние имена или обновить пути в index.html. Социальные логотипы загружаются с внешних адресов.

## Мобильная версия

Предусмотрены адаптивные правила для экранов до 1120, 760 и 480 px, раскрывающееся меню и одна колонка контактов на узких экранах. Адаптивность проверена по HTML, CSS и логике JavaScript; визуальная проверка в мобильном браузере не выполнена.
